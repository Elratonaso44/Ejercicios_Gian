# Misión: consumir la API de la escuela desde Angular

## Por qué
El usuario ya construyó una API en Node.js para estudiantes y profesores y quiere usarla en una aplicación Angular para su tarea escolar. La meta inmediata es consultar profesores; el usuario conoce JavaScript, pero todavía no TypeScript ni Angular, así que aprenderemos con cambios pequeños y explicados.

## Éxito significa
- Crear una aplicación Angular en TypeScript que consulte la API existente y muestre profesores.
- Entender el recorrido navegador → Angular → Express → MySQL → JSON → pantalla.
- Luego agregar, modificar y eliminar profesores usando la autenticación Bearer JWT de la API.
- Repetir el patrón con estudiantes cuando profesores funcione.

## Límites
- Avanzar paso a paso, explicando los conceptos nuevos sobre ejemplos de este repo.
- Conservar la API Node actual como backend y probar primero lectura de profesores.
- No tocar registros de la base de datos en los primeros pasos.

## Fuera de alcance por ahora
- Implementar estudiantes antes de completar profesores.
- Reescribir el backend o cambiar el esquema MySQL.
